# Benchmark protocol

## Authority and lifecycle

Rows progress through `DISCOVERED`, `RIGHTS_CLEAR`, `PRIMARY_REPLAYED`, `DUAL_CURATED`,
`ADJUDICATED`, `LEAKAGE_CLEAR`, `INDEPENDENCE_LOCKED`, and `FROZEN`. `REJECTED` and `QUARANTINED`
do not enter a freeze. Database annotations can seed discovery but never establish causal truth.

Each causal row needs a versioned plant gene and assembly, exact trait direction and phenotype
protocol, mapped interval, population/cohort/panel receipts, a primary causal experiment, an
orthogonal confirmation, two distinct curators, an independent adjudicator, and replayable
pre-truth evidence whose cutoff predates the earliest public answer.

Each countable null needs a predeclared negligible-effect margin, an effect interval entirely within
that margin, adequate power, working positive controls, an independent QC review, and a pre-truth
evidence snapshot. A nonsignificant p-value, missing annotation, random gene, phenotype permutation,
matched decoy, or validator-negative case is not an empirical null denominator.

## Independence

The counting graph unions rows that share a study, cohort, population, lineage root, orthogroup, or
source. Connected components—not file lines—are effective units. A real evaluation contract refuses
multiple rows from the same target component. Missing keys quarantine a row instead of creating a
singleton.

Species designated for external replication cannot appear in development, calibration, or internal
holdout. The primary policy also requires orthogroup disjointness; any relaxed sensitivity analysis
must be separately labeled.

## Statistical gate

The contract floor is 35 independent causal units and 73 independent empirical equivalence nulls.
Those figures are zero-error minima for the existing two-sided 95% Wilson ceilings; they are not a
universal power analysis. Every evaluation additionally requires a frozen power-analysis receipt.
Missing and conflicting outputs remain in denominators as abstentions or failures under the
downstream evaluation plan.

## Blind execution

1. Freeze the rules, code artifact, analysis plan, power analysis, sources, selected rows, and split.
2. PhytoBench creates opaque mixed cases and salted truth commitments.
3. Deliver only `runner/` to the offline method operator.
4. Keep `supervisor/` under independent control.
5. Seal the complete primary output before revealing salts or truth.
6. Replay commitments, count every case, and label any later run `POST_HOLDOUT`.

## Claim boundary

A structurally valid curation freeze is not a ready benchmark. A ready benchmark is not a successful
method. A successful internal benchmark is not external replication. External replication is not
experimental authorization. Claims advance only when the corresponding immutable evidence exists.
